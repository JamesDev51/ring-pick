## 1. 문서 목적

기존 Ring Pick v2는 기능적으로 출시 가능한 상태까지 구현되었다. 빠른 진단, 개인화 16강, 전체 64강, 결과 저장/공유, 세션 복원, 모바일 대응, CI/E2E 및 Vercel Production 배포까지 완료되어 있다.

하지만 제품 전체 완성도를 100%라고 선언하기에는 한 가지 큰 차이가 남아 있다.

**현재 웨딩밴드 자산은 실제 국내 웨딩샵 상품 사진 수준의 실사감보다 렌더/생성 이미지 느낌이 강하다.**

따라서 v2.1의 목표는 기존 기능을 다시 만드는 것이 아니라 아래 세 가지를 마무리하는 것이다.

1. 실제 구매 후보처럼 느껴지는 **포토리얼 웨딩밴드 이미지 153장** 완성
2. 진단용 A/B 이미지가 정말 한 속성만 비교하도록 **공정성 검수**
3. 실제 사용자 5~10명의 무설명 테스트를 통한 **최종 신뢰도 검증**

## 2. 제품 정의

### 2.1 핵심 한 문장

> **매일 끼고 싶은 내 웨딩밴드 취향을, 반지 이미지를 고르면서 정리하는 모바일 전용 서비스.**

### 2.2 해결하려는 문제

웨딩밴드 매장에 가기 전 사용자는 아래를 말로 설명하기 어렵다.

- 나는 민자를 좋아하는지 작은 다이아를 좋아하는지
- 얇은 밴드와 두꺼운 밴드 중 어느 쪽이 좋은지
- 유광/무광/헤어라인 중 어떤 질감이 좋은지
- 실버톤/샴페인톤/옐로/로즈 중 어떤 색감이 좋은지
- 사선, V, 웨이브, 투톤, 홈, 구조적인 밴드 중 무엇이 끌리는지
- 신랑/신부가 완전히 같은 링을 해야 하는지, 같은 모티프만 공유해도 되는지

Ring Pick은 이 취향을 이미지 선택으로 수집하고, 최종적으로 매장에서 보여줄 수 있는 문장과 후보를 제공한다.

### 2.3 명확한 비목표

이번 v2.1의 메인은 **프로포즈링/큰 센터 다이아 반지 테스트가 아니다.**

- 0.8ct~2ct급 솔리테어 중심 후보군 제외
- 다이아 컷 등급, 컬러 등급, 감정서 비교 제외
- 가격 비교 제외
- 특정 브랜드 추천 제외
- 특정 명품 고유 디자인 복제 제외
- 실제 합금/함량 판정 제외

큰 센터 스톤 중심의 프로포즈링 테스트는 별도 후속 기능으로 분리한다.

## 4. 현재 가장 큰 제품 문제

기능이 아니라 **이미지 현실성**이다.

기존 자산은 자동 검증, 속성 차이, 반응형 웹 전달을 위해 만들어진 렌더형 이미지다. 기능 검증에는 충분하지만 실제 웨딩밴드를 사려는 사용자의 관점에서는 다음 문제가 남는다.

- AI/CG 느낌이 남음
- 실제 국내 웨딩샵 상품 사진과 질감 차이가 큼
- 밴드가 지나치게 완벽하고 플라스틱처럼 보이는 경우가 있음
- 작은 포인트 다이아, 홈, 무광, 헤어라인 같은 차이가 약하게 보임
- 실버 계열 반지가 아이보리 배경에서 묻히는 경우가 있음
- 일부 후보가 실제로 구매하고 싶은 디자인보다는 생성 모델이 만들기 쉬운 디자인처럼 보임

### 4.1 방향 전환의 근거

서비스는 이미 큰 센터 다이아 중심에서 한국형 웨딩밴드 중심으로 재설계되었다.

중요한 후보는 다음과 같은 실제 웨딩밴드 문법이다.

- 완전 민자
- 작은 포인트 다이아 1개
- 3~7개의 짧은 다이아 라인
- 사선 또는 V형 세팅
- 하프 파베
- 밀그레인
- 무광/헤어라인
- 홈/베벨/다면 구조
- 투톤
- 웨이브/트위스트
- 낮고 작은 센터 스톤

## 7. 진단 구조

### 7.1 질문 수

총 **18문항**.

### 7.2 진단 원칙

한 질문에서 A/B는 **질문하는 속성 한 가지만 달라야 한다.**

예:

- 유광 vs 새틴 무광
- 민자 vs 작은 포인트 다이아
- 작은 포인트 vs 짧은 다이아 라인
- 짧은 라인 vs 하프 파베
- 오벌 단면 vs 플랫 단면
- 얇은 밴드 vs 중간 밴드
- 실버톤 vs 샴페인톤
- 옐로톤 vs 로즈톤
- 단색 vs 투톤
- 직선형 vs 웨이브형

### 7.3 진단 이미지

총 **25개 원본 이미지**를 재사용해 18개의 통제형 A/B 질문을 구성한다.

최종 포토리얼 이미지로 바꾼 이후에도 현재 질문 ID와 취향 점수 체계는 유지한다.

### 8.2 이미지 제작 방식

모든 디자인을 하나의 기준 링에서 억지로 변형하지 않는다.

**9개 디자인군별 마스터 + 공통 손 모델**을 먼저 승인한 뒤 각 후보를 파생한다.

#### M01 — 클래식 민자

- 화이트골드/플래티넘 느낌의 쿨 실버톤
- 약 2.5mm 인상
- 하프라운드
- 완전 유광 민자
- 다이아 없음
- 로고 없음
- 실제 웨딩샵 상세페이지 촬영 느낌

**현재 상태:** ChatGPT 이미지 생성으로 첫 실사 단독컷 샘플 생성 완료. 아직 최종 자산으로 GitHub에 반영하지 않음.

#### M02 — 포인트 다이아

- M01과 같은 현실적인 밴드 비율
- 작은 멜리 다이아 1개 또는 소수
- 과한 센터 스톤 금지

#### M03 — 라인 세팅

- 짧은 일자/사선/V 라인
- 다이아는 밴드에 낮게 매립

#### M04 — 파베

- 1/4~하프 파베
- 실제 착용 가능한 낮은 높이
- 센터 스톤 없음

#### M05 — 구조형

- 중앙 홈
- 베벨
- 다면
- 세그먼트
- 구조가 실제 제작 가능해야 함

#### M06 — 텍스처

- 새틴
- 헤어라인
- 밀그레인
- 해머드
- 표면 질감이 사진에서 명확히 식별되어야 함

#### M07 — 투톤

- 두 금속 색의 경계가 실제 제작물처럼 선명
- 녹아 섞인 듯한 AI 표현 금지

#### M08 — 웨이브/트위스트

- 과도하게 복잡하지 않은 웨이브, V, 교차
- 실제 일상 착용 가능한 형태

#### M09 — 쁘띠 센터

- 약 0.1~0.3ct 인상
- 낮은 프롱/베젤
- 기존 v1 솔리테어처럼 큰 스톤 금지

#### MW01 — 공통 손 모델

- 여성 손 1종 고정
- 왼손 약지
- 자연스러운 중간 피부톤
- 짧은 누드톤 네일
- 다른 반지/팔찌 없음
- 손 각도와 조명 고정
- 모든 worn 이미지에서 손의 크기와 구도 최대한 동일

## 9. 사진 스타일 규격

### 9.1 단독컷

- 1:1
- 밝은 아이보리 또는 웜 라이트 그레이 배경
- 3/4 상단 시점
- 밴드 형태가 정확히 보이는 각도
- 자연스러운 접지 그림자
- 실제 주얼리 스튜디오 느낌
- 과도한 bloom/glow 금지
- 금속이 플라스틱처럼 보이면 탈락
- 불필요한 박스/꽃/소품/로고/텍스트 금지

### 9.2 착용컷

- 동일 후보 단독컷과 같은 디자인
- 왼손 약지
- 실제 웨딩밴드 착용 비율
- 손가락 관통/밴드 단절 금지
- 실제보다 과장된 스톤 크기 금지
- 라이프스타일 광고보다 웨딩샵 착용 참고사진에 가까운 톤

## 10. 이미지 즉시 탈락 기준

아래 중 하나라도 발생하면 재생성한다.

- 손가락 개수 오류
- 약지가 아닌 곳에 착용
- 밴드가 손가락을 관통
- 단독컷과 착용컷 디자인 불일치
- 다이아 개수/배치 불일치
- 투톤 경계가 녹아서 섞임
- 금속 표면이 플라스틱/고무처럼 보임
- 제작 불가능한 세팅
- 다이아가 공중에 떠 있음
- 작은 다이아 후보에 갑자기 큰 센터 스톤 추가
- 민자 후보에 임의 장식 추가
- 특정 브랜드 로고 또는 고유 문양 복제
- 배경/카메라 각도가 후보별로 지나치게 달라짐

- 밴드 두께

- 다이아 크기(다이아 관련 문항 제외)
- 반지 위치

### 예시

`유광 vs 무광`

- 변경 가능: 표면 finish
- 변경 금지: 폭, 색감, 다이아, 각도, 반지 크기

`실버톤 vs 샴페인톤`

- 변경 가능: metal tone
- 변경 금지: 폭, 표면, 다이아, 구조

`민자 vs 포인트 다이아`

- 변경 가능: 작은 다이아 추가 여부
- 변경 금지: 밴드 폭, 금속 색, 표면, 구조

구조를 유지한다.

## 16. 결과 문구 QA

결과 문구는 실제 사용자가 직원에게 보여줘도 자연스러워야 한다.

### 좋은 매장용 문장 예

> 차가운 실버톤의 중간 폭 밴드를 찾고 있어요. 반짝임은 작은 포인트 정도가 좋고 전체 파베처럼 화려한 디자인은 부담스러워요. 오벌이나 부드러운 플랫 단면부터 보고 싶어요.

### 금지

- 의미 없는 `AI 추천` 문체
- 지나치게 전문적인 주얼리 용어 남발
- 사진만으로 소재를 확정하는 표현
- `당신은 ~입니다` 식 과도한 단정

## 17. 추천 대안 품질

## 20. 실제 사용자 테스트

자동화 테스트로는 이미지 신뢰도와 구매 의사결정 유용성을 완전히 검증할 수 없다.

### 대상

실제 결혼 준비 중이거나 웨딩밴드를 고민해본 사용자 **5~10명**.

가능하면 설명 없이 링크만 전달한다.

### 핵심 질문

1. 결과가 실제 본인 취향 같았는가?
2. 비교 중 차이가 잘 안 보이거나 헷갈린 사진이 있었는가?
3. 이 결과를 반지샵에 가져가면 도움이 될 것 같은가?

### 추가 관찰

- 첫 화면에서 서비스 목적을 바로 이해하는가
- 18문항이 지루하지 않은가
- 어느 질문에서 오래 멈추는가
- 결과를 캡처/공유하고 싶은가
- 대안 3개가 의미 있게 다른가

### 수정 기준

동일한 문제를 **2명 이상**이 독립적으로 제기하면 수정 대상으로 본다.

## 26. 최종 판단

현재 Ring Pick은 **기능적으로는 출시 가능한 완성 상태**다.

남은 마지막 품질 차이는 코드가 아니라 아래 세 영역이다.

1. **실사 이미지 현실성**
2. **진단 이미지 공정성**
3. **실제 사용자 신뢰도**

따라서 v2.1에서는 기능을 확장하지 않고 이 세 가지에 집중한다.

100% 완성의 정의는 “더 이상 아이디어가 없다”가 아니라, 이 PRD에 정의된 Release Gate를 모두 통과해 **사용자가 실제 웨딩밴드 구매 전 참고 도구로 신뢰할 수 있는 상태**에 도달하는 것이다.
